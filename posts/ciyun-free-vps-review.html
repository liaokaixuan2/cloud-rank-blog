四、建站实战：5 分钟起一个 Nginx 站点

空跑分不算真本事，直接上手建站。Ubuntu 24.04 下装 Nginx 一条命令的事：

apt update -y
apt install nginx -y
systemctl enable --now nginx
# 放一个测试首页
echo "Hello, ciyundata!" > /var/www/html/index.html

然后在慈云数据的控制台安全组里放行 80 / 443 端口，浏览器输入服务器 IP，页面就出来了。如果要绑自己的域名，两步：

  1. 在域名解析面板添加 A 记录指向服务器 IP（子域名也可以用 CNAME）；
  2. 用 certbot 一键签发 Let's Encrypt 免费证书：
apt install certbot python3-certbot-nginx -y
certbot --nginx -d yourdomain.com

2G 内存在这套流程里绰绰有余：Nginx 常驻内存几十 MB，剩下的空间足够再挂一个 Uptime-Kuma 探针、一个静态博客或者跑跑脚本。作为个人建站学习机，这个配置刚好够用又不浪费。
